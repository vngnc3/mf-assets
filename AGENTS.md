# AGENTS.md — Mata Foundry Digital Assets

## Project Overview

`mf-assets` is a free, open-source (MIT) Blender asset library of Geometry Node-based VFX tools — camera rigs, cloth sims, hair effects, and more. The product is a `.blend` file with embedded node graphs, distributed as a **Blender 5.2+ remote asset library** (online asset repository): users register `https://blender.mata.bot` in Blender Preferences and assets download on demand.

**Deployment (live since 2026-08-07):** R2 bucket `mf-assets` (Cloudflare) → custom domain `blender.mata.bot`, synced with rclone. 12 assets, all min Blender 5.2.

Current assets:
- **Camera Alexa 65 Anamorphic** — ARRI Alexa 65 cinema camera rig with anamorphic lens
- **Camera IMAX 70 Anamorphic** — IMAX 70 cinema camera rig with anamorphic lens
- **Detangle Cloth** — Geometry Nodes modifier that untangles intersecting cloth
- **Fake Cloud** — procedural cloud generator
- **Fake Wind Cloth** — Geometry Nodes wind simulation for cloth meshes
- **Fake Wind Hair Curves** — Geometry Nodes wind effect for hair curves
- **Generate Rock** — procedural rock generator
- **Point Velocity** — calculates point velocity from a deforming geometry (constant point count)
- **Points to Liquid Mesh** — meshes a set of points into a liquid-like surface using SDF
- **Rainy Surface** — generates and simulates raindrops on a surface
- **Random Rotation** — utility node group for random rotation
- **Material.RainySurfaceAttributes** — rainy surface shader that accepts attributes from Rainy Surface

## Remote Asset Library — how it works

- A remote library is a directory served over plain static HTTP containing three things: the assets (`.blend` files, **fully self-contained**), a JSON listing describing them, and WebP preview images.
- Blender 5.2+ browses the listing in the Asset Browser and downloads a `.blend` only when an asset is actually used (download on demand).
- **Every `.blend` must be self-contained**: no linked files, all textures/media PACKED into the file. Multiple assets per file are fine, but importing one asset downloads the whole file.
- The listing is generated by Blender itself: `blender -b -c asset_listing generate <assets-dir>` (pass the DIRECTORY, not the blend file; assets must be marked as assets).
- The generator preserves `_asset-library-meta.json` name/contact edits across runs.
- Deep dive on the protocol/schema: homelab pipeline README at `~/songbird/blender-assets/` (scripts: build.sh / sync.sh / verify.sh) and vault reference `songbird-vault/reference/blender-online-assets-repo.md`.

## Update Loop (publishing a new version)

1. Open `assets/fx_mfAssets_main_online.blend` in Blender, make changes, mark datablocks as assets, assign `_MF Assets` catalog.
2. Regenerate the listing: `blender -b -c asset_listing generate <path>/assets` — regenerates `_v1/*` and thumbnails.
3. Commit + push this repo.
4. Sync to R2 + verify:
   - homelab: `~/songbird/blender-assets/scripts/sync.sh` then `./verify.sh https://blender.mata.bot`
   - or izzy's machine: Dropbox copy at `~/Dropbox/mpyu-bridge/blender-assets/` (build.sh/sync.sh/README)
5. Verify output must pass (sha256 + query-string audit) before announcing.

## Asset Organization (inside the .blend)

- **Catalog**: All assets under `_MF Assets` (underscore prefix sorts first in Asset Browser)
- **Node group naming**: `NT<Name>` — e.g. `NTDetangle Cloth`, `NTFake Wind Hair Curves`
- **Object naming**: `bOB<Name>` or `OB<Name>` — e.g. `bOBCamera.Alexa65.Anamorphic`, `OBCloth`
- **Collections**: `Scene Collection`, `camera`, `geo`

## External Dependencies (hard-referenced in .blend)

- **Flip Fluids addon** — materials library (FF Water, FF Beer, FF Blood, etc.) for rendering
- **Blender bundled hair assets** — `procedural_hair_node_assets.blend` (Smooth, Clump, Frizz nodes)
- These are developer-machine paths; users need the addons installed for full functionality

## Conventions

- **File names**: lowercase with underscores — `camera.alexa65.png`, `fakewindcloth.png`
- **Commits**: conventional, descriptive messages
- **Git**: single `main` branch, no GitHub workflows/actions
- **Generated files**: `assets/_v1/*`, `assets/*_thumbnails/` are build artifacts — always regenerate, never hand-edit the JSON
- **Versioning**: the `.blend` file itself is the version; consider `git tag vX.Y.Z` per release

## Common Tasks for Agents

### Using the remote library (users, Blender 5.2+)
1. Preferences → Asset Libraries → add online library → `https://blender.mata.bot`
2. Requires *Allow Internet Access* (Preferences → System → Network)
3. Browse `_MF Assets` catalog, click to download on demand (append/pack only, no link)

### Installing/using locally (dev)
1. Clone repo: `git clone https://github.com/vngnc3/mf-assets.git`
2. In Blender → Preferences → File Paths → Asset Libraries, add the `assets/` directory
3. Open Asset Browser, select `_MF Assets` catalog, drag assets into scene

### Adding a new asset
1. Open `assets/fx_mfAssets_main_online.blend` in Blender
2. Create Geometry Node group with `NT` prefix naming
3. Mark as asset, assign to `_MF Assets` catalog
4. Create/export a PNG preview icon to `icons/`
5. Update `icons/mf-assets-icons.af` with the new icon design
6. Save, regenerate the listing, commit + push (see Update Loop)

### Updating icons
1. Edit `icons/mf-assets-icons.af` in Affinity Designer
2. Export individual PNGs to `icons/`
3. Reassign previews to assets inside the `.blend` if needed

## Notes

- `.blend1` files are Blender auto-backups and are gitignored
- The `.blend` is Zstandard-compressed (Blender 5.1+ default)
- Preview icons are embedded in the `.blend` as asset metadata, but source PNGs live in `icons/`
- Cloudflare bot-fight mode must stay OFF for `blender.mata.bot` (it blocks non-browser user agents — Blender's downloads would 403)
- The GitHub README is user-facing install docs and may lag the current state; AGENTS.md is the source of truth for agents
